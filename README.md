# 金牌面试官 · 新人面试官培训课件

这是一个面向面试官、HRBP 和业务负责人的内部培训课件，基于候选人满意度反馈与面试官手册沉淀，目标是让人一眼知道“照着做就行”。

## 设计原则

目标不是炫技，而是让使用者一眼知道“照着做就行”。

- 每一页只解决一个议题
- 信息层级一眼可分
- 白色近底 + 近黑墨色 + 主题绿色点缀
- 正文不小于 24px
- 动效只允许 0.25s 以内的淡入上移
- AI 图统一用玻璃容器承载，不抢文字
- 禁止紫色渐变、emoji 图标、厚黑阴影、重复模板对称、假数据、空卡片

## 课件内容

课件共 27 页，覆盖新人面试官从准备到决策的完整流程：

- 封面与培训定位
- 招聘常见痛点与四大误区
- 面试官四大角色
- 结构化面试流程
- STAR 行为面试法
- 面试前 / 中 / 后标准动作
- 五要五不要
- 统一评分四维度与决策原则
- 合规红线与信息安全
- 新人 SOP 一页纸

## 技术特点

- 单文件自包含 HTML，无外部依赖、无构建步骤
- 1920×1080 固定画布，自适应缩放
- 支持键盘翻页、全屏演示、打印 / 导出 PDF
- 内置 AI 配图与统一视觉容器

## 在线演示与本地运行

在线演示：https://zhaohuic51-ops.github.io/golden-interviewer/

## 目录结构

```text
golden-interviewer/
├── README.md              # 项目说明文档
├── index.html             # 课件演示文件（自包含单文件，无外部依赖）
├── .nojekyll              # 让 GitHub Pages 按普通静态文件发布
└── .github/
    └── workflows/
        └── deploy.yml     # push 到 main 后自动部署到 GitHub Pages
```

## 更新与部署

修改课件后，将 `index.html` 等文件提交并 push 到 `main` 分支，GitHub Actions 会自动部署到 GitHub Pages。
